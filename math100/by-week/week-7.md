## Functions
___
A relation $R$ from set $X$ to set $Y$ is a function if and only if it satisfies these properties:
$$
1) \space \ \ \forall x \in X, \exists y \in Y \text{ s.t. } (x,y) \in R \\
\space \\
2) \space \ \ (x,y) \in R \land (x,z) \in R \implies y=z 
$$
