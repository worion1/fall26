## Expectation
___
Consider a discrete random variable $X$ with PMF $p_X(x) = P(X=x)$. So far, we have constructed discrete probability distributions that tell us about the likelihood of the event $\set{X = x}$ occurring for all real $x$. A question that naturally follows asks about what value $x$ would we *expect* to get if we ran the experiment many times. For example, if $X$ counts the heads on a fair coin toss, a common (yet trivially answered) question may be, "Do I expect to get heads more or tails more if I flipped many coins?" Obviously, since the odds are 50/50 for a fair coin toss, the expected value of heads over many iterations is simply 0.5 heads. Notice that 0.5 isn't actually a possible value that $X$ can take on, that is, $0.5 \not\in S_X$. This is perfectly fine, and nonetheless, this example gives us the right intuition as to the expected value of a discrete random variable is actually computed. We took the probability of getting heads and multiplied it by the real number that getting heads corresponds to, ${X=1}$.

The expected value of a discrete random variable with a finite support and valid PMF is:
$$\mathbb{E}[X]=\sum_{x\in S_X}xp_x(x)=\mu$$
Note that this sum resembles a weighted average, where each value in the support of $X$ is weighted by it's corresponding probability in the probability distribution. Also note that if $p_X(x)$ were simply $\frac{1}{N}$, where $N = |S_X|$, this would just be an arithmetic average. Thus, we can also describe the expected value as the *mean*, usually denoted as $\mu$. Now the fact that the expected value need not be a value contained by $S_X$ makes sense because we understand it to simply be a weighted average, not an expected observable outcome for a single run of an experiment.

Because $\mathbb{E}[X]$ is defined by the linear operator $\sum$, it shares it's linear properties, namely additivity ($\mathbb{E}[X+Y]=\mathbb{E}[X] + \mathbb{E}[Y]$), homogeneity ($\mathbb{E}[aX] = a\mathbb{E}[X]$). Furthermore, because $\mathbb{E}[X]$ is defined as a sum over the support of $X$, the operator retains closure of the sign of $X$ and bounds (e.g. $X \le Y$, $a \le X \le B$). Another property of the operator comes directly from it's definition as a sum that runs over $S_X$. Consider $X$ such that $S_X = \set{41}$, that is, the only value taken on by $X$ is $41$. Then, if we plug this into the sum definition of $\mathbb{E}[X]$, we simply get $41\cdot 1=41$ since the probability of an element of $S_X$ which only contains one element is simply $1$. Thus, $\mathbb{E}[c] = c$.
