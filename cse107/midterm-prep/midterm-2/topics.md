<u>integration</u>
List of all integral problem types:
- $P((X,Y) \in A) = \iint_{S\cap A}f_{X,Y}(x,y)dA$ (note that performing this double integral yields a scalar, which is what we expect a probability to be)
- $f_X(x) = \int_{S_Y} f_{X,Y}(x,y) dy$ (note that $f(x,y)$ is bivariate, but we are only integrating with respect to $y$. This ensures that the output is a function of $x$ or constant).
- $f_Y(y) = \int_{S_X}f_{X,Y}(x,y)dx$
- $P(X \in A | Y=b) = \int_A f_{X|Y}(x|b)dx$
- $P(Y \in A|X=b) = \int_A f_{Y|X}(y|b)dy$
- $\mathbb{E}[X|Y] = \int_{D(f(x|y))}xf_{X|Y}(x|y)dx$ (note that $Y$ is not fixed here yet, so we expect a function)
- $\mathbb{E}[Y|X] = \int_{D(f(y|x))}yf_{Y|X}(y|x)dy$ (same here)
- $\mathbb{E}[X|Y=b] = \int_{D(f(x|y))}xf_{X|Y}(x|b)dx$ (note that we fixed $Y$ here, so we expect a scalar representing the mean of $X$)
- $\mathbb{E}[Y|X=b] = \int_{D(f(y|x))}yf_{Y|X}(y|b)dy$
- $\mathbb{E}[g(X,Y)] = \iint_{S_{X,Y}}g(x,y)f_{X,Y}(x,y)dA$ (note that we are computing a double integral over bivariate $f_{X,Y}(x,y)$ so the result is of course a scalar representing the mean of $Z = g(X,Y)$).
